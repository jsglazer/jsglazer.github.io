I am an incoming PhD student in public policy. Before I start school, I decided to prepare a modern workflow for taking digital/ paper notes, managing research, and drafting papers. I leveraged the amazing work of developers who build plug-ins for Zotero and Obsidian, namely windingwind's zotero-better-notes and obsidian-zotero-integration. I am releasing a modernized set of these plug-ins, plus other tools, which offer greater efficiency, more features, and enhanced security compared with their predecessors.

Workflow Overview

The integrated environment standardizes document collection, annotation, bibliographic management, document exporting, and note review into a systematic pipeline. This collection of software and plugins reduces the friction in the previously available set of tools. The workflow consists of the following core tasks:

  • Reading and Annotating PDFs in Zotero: Annotate (highlight & comment) PDFs and create templated notes. Sync the notes with a two-way link to Obsidian. Assign custom labels to Zotero highlight colors and sync that customization with imported notes in Obsidian.
  • Annotating Markdown in Obsidian: Annotate both synced notes and original files using MD Annotation, a delimiter-free tool that shows notes in the margin and/or a sidebar. No errant text is introduced in the note body text (all meta data is at bottom of file).
  • Synthesizing Knowledge via the HAL System: Notes and articles are collected in a structured folder system (modeled after compiler architecture) where an LLM can automatically index materials, write document summaries (DocSum/), and identify logical connections (Connections/) to build a cross-referenced research wiki.
  • Adding Citations Directly from Zotero: Citations and bibliography details are pulled dynamically into Obsidian notes using Zotero Manager. The plugin include both a direct database query to Zotero as well as a Web API fallbacks.
  • Memorizing content: ENTER Anki info here
  • Document Export: Export markdown documents with headers, footers, page number, and other customizations using Multi Exporter. There are options for exporting multiple files. Profiles can be configured for articles, manuscripts, data-heavy products, or other styles. Future output pipelines will support LaTeX, Microsoft Word/Powerpoint, and Apple Keynote.

Software & Plugin Overview

Detailed specifications, feature matrices, setup requirements, and migration information for each component are provided on their dedicated subpages:

Core Platforms

  • Zotero: Free, open-source reference manager that acts as the library for research document in PDF, ePub, and other formats. Extracts meta (citation) data and provides annotation and commenting PDF assets.
  • Obsidian: Highly customizable Markdown editor that serves as the hub for all rresearch, knowledge management, and writing.
  • HAL System: A compiler-modeled set of folders inside Obsidian that structures raw notes and session logs into a consistent, cross-referenced academic wiki.

Plugins & Tools

  • Enhanced Notes for Zotero: A safe, sandbox-oriented fork of zotero-better-notes that synchronizes PDF reader annotations with Obsidian notes using Liquid templates and TypeScript security.
  • Zotero Highlighter Descriptions: A Zotero plugin that maps default highlight colors to custom semantic and cognitive coding labels.
  • Zotero Converter: A Zotero utility plugin that converts non-PDF digital documents (EPUBs, web clippings, text files) into standardized PDF formats for unified annotation.
  • Zotero Manager for Obsidian: A modernized integration plugin that pulls citations, references, and annotations into Obsidian, supporting Web API fallback and Nunjucks persist blocks.
  • MD Annotation for Obsidian: A delimiter-free markdown annotation and comment plugin that stores highlights out-of-band to preserve note body clean text.
  • Multi Exporter for Obsidian: A desktop-only Obsidian exporter that pagination-renders previews and PDFs using CSS Paged Media.
  • Equation Library for Obsidian: A pop-up library of reusable math formulas with a live WYSIWYG LaTeX generator and $/ editor autocomplete, for desktop and mobile.

Standalone Apps

Not part of the Zotero/Obsidian research pipeline, but built with the same tooling and shared here as related projects.

  • MathPractice: A macOS & iOS calculus drill app built around solving problems on paper, with adaptive difficulty, incremental derivation reveals, and CloudKit sync across devices.
