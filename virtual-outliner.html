Overview

Virtual Outliner is an outline mode for Obsidian. It allows you to show and hide an outline inside a working Markdown (MD)document. The MD text (i.e., prose) can also be selectively hidden and shown. The idea is that you can fully outline a a document, start writing within the outline, update the outline, show/hide the prose, and show/hide the outline as you see fit.
