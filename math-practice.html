MathPractice

GitHub Repository: github.com/jsglazer/math-practice

Overview

MathPractice is a native macOS & iOS calculus drill app, built around working problems on paper rather than typing answers into a screen. Pick a topic and sub-type, get a problem, solve it by hand, then ask to see the answer — separately, ask to see the derivation one step at a time. Self-report right or wrong, and the app tracks that record per problem type and adjusts difficulty accordingly. It is a standalone project, unrelated to the Zotero/Obsidian research workflow described elsewhere on this site.

Most math apps are answer-entry quiz engines that grade a typed answer and dump the full solution as one wall of text. MathPractice inverts all three: it never asks for the answer, it gates disclosure behind explicit requests, and it reveals the derivation incrementally so a stuck problem can be unstuck with the smallest possible hint.

Features

  • No answer entry, no grading: Correctness is a self-reported Right/Wrong — the app is a drill partner, not an examiner.
  • Incremental reveal: "Show next step" releases one more line of the derivation at a time; "Show answer" releases the final answer.
  • Adaptive difficulty (1–10), tracked independently per topic/sub-type pair, with a configurable ladder (harder after N correct in a row, easier after M wrong, with a hold period).
  • 24 derivative templates across power, product, quotient, chain, trigonometric, exponential/logarithmic, and partial-derivative rules — every template verified against SymPy at build time before it ships.
  • Progress matrix & session history: Topic × sub-type × difficulty view, plus a browsable log of past practice sessions.
  • Key problems & notes: Star any problem, attach a note, and export starred problems (or a full session) to PDF.
  • PDF worksheets (macOS): Export a worksheet, work it on paper, then self-report by question number.
  • Problem-pack import: Load JSON packs of LLM-authored problems for cases the built-in templates handle poorly.
  • Multi-device sync via CloudKit: Two Macs and an iPhone converge on the same state via an append-only, order-independent event log — no synced mutable "difficulty" field to conflict.

v1 topic scope is derivatives. Integrals, limits, and advanced algebra are planned as additional topics.

Requirements & Installation

  1. Build from source: Requires Xcode 16+ and XcodeGen. 
    swift test                      # headless gate — no Xcode project, no Python, no network
xcodegen generate
xcodebuild -project MathPractice.xcodeproj -scheme MathPractice     -destination 'platform=macOS' build
xcodebuild -project MathPractice.xcodeproj -scheme MathPractice-iOS -destination 'generic/platform=iOS' build
  2. Releases: Signed builds are published on the GitHub releases page.

Correctness

There is no computer algebra system bundled in the app. Each template states its own derivative in closed form; a build-time tool (Tools/verify_templates/) runs every template across fixed seeds and difficulties, differentiates the generated problem with SymPy, and refuses to write the golden fixture unless the stated answer and the last worked-solution step are symbolically equal to it. The shipped Swift test suite then only needs to reproduce that golden fixture byte for byte — SymPy itself is never shipped or a runtime/test dependency.
