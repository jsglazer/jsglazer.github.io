# MD Annotation for Obsidian

## Overview
MD Annotation (`md-annotation`) is an Obsidian plugin developed by jsglazer that enables delimiter-free annotations and comments on markdown documents. Traditional note highlighting modifies the document body by adding syntax (e.g., `==highlight==` or HTML `<mark>` tags), which clutters the raw text. MD Annotation stores annotations out-of-band (managed via a sidebar interface) to keep the raw markdown notes clean, readable, and highly portable.

## Features
- **Delimiter-Free Highlighting**: Select and highlight any text range in the Obsidian editor without modifying the actual document body content.
- **Annotation Sidebar**: A dedicated view to manage, browse, edit, and delete highlights and comments across the active document.
- **Gutter Toggles**: Supports toggling annotation and comment indicators in the editor gutter for a clean writing interface.
- **Quick-Apply Commands**: Keyboard shortcuts and command palette integration for applying specific classifications:
  - `md-annotation:apply-Key`
  - `md-annotation:apply-Define`
  - `md-annotation:open-sidebar`
- **Metadata Separation**: Saves annotation coordinates and comment content at the bottom of the markdown file under a standard `%%md-annotation` block, ensuring the primary prose remains clean while maintaining self-contained files.

## Requirements
- Obsidian 1.7.2+ (desktop or mobile).

## Migration
- **Clean Markdown Body**: Transitioning to MD Annotation replaces messy inline markup (like HTML tags generated by Chetachi's `Highlightr` or standard Markdown `==` delimiters) with clean text.
- **Data Preservation**: Existing notes can be annotated directly; the plugin reads and appends metadata blocks at the bottom of the files without interfering with existing text layout.
