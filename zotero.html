Zotero

Official Website: zotero.org

Overview

Zotero is a free, open-source reference management tool designed to collect, organize, cite, and share research sources. In this workflow, Zotero acts as the source of truth for academic library documents (PDFs, metadata), enabling researchers to annotate digital texts, harvest metadata from the web, and sync annotations downstream into Markdown notes.

Features

  • One-Click Reference Harvesting: Save citations, web snapshots, and PDFs directly from your browser to your Zotero library using the Zotero Connector extension.
  • Built-in PDF Reader & Annotation: Read and annotate documents with highlights and margin comments. Highlight colors can be mapped to custom semantic tags.
  • Metadata Parent-Child Relationships: Attaches files, web notes, and translated annotations directly as child items of a parent bibliographic entry.
  • Cloud Syncing: Sync bibliography data and PDFs across multiple devices using Zotero's cloud service or local WebDAV configurations.

Requirements & Installation

  1. Download & Install: Install Zotero from the official Zotero site.
  2. Install Browser Extension: Add the Zotero Connector extension to your web browser (Chrome, Safari, or Firefox).
  3. Install Workflow Plugins:
    • Go to Zotero > Tools > Add-ons.
    • Install the plugin releases of Better Notes, Highlighter Descriptions, and Zotero Converter.

Migration

Organizing PDF chaos: Shifts your reference library from flat directories of unnamed PDFs into a structured database where articles are labeled, cross-referenced, and ready for automated markdown notes exports.
