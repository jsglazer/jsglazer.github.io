Equation Library for Obsidian

GitHub Repository: github.com/jsglazer/equation-library

Overview

Equation Library (equation-library) is an Obsidian plugin developed by jsglazer that provides a pop-up library of reusable math formulas, backed by a live WYSIWYG LaTeX generator. Build an equation and watch it render as you type, save the ones you use again, and drop any of them into a note as inline ($…$) or block ($$…$$) math. A $/ autocomplete trigger surfaces the same library directly from the editor. It runs on macOS, Windows, Linux, iOS, and Android.

Features

  • Library popup: Run Show Equation Library from the command palette or click the sigma icon in the ribbon. Saved equations render as scrolling tiles — click to load one into the generator, double-click to insert it inline, shift + double-click to insert it as a block, right-click to rename, re-categorize, or delete.
  • Live WYSIWYG generator: A math field where structure appears as you type (e.g. \frac becomes a two-slot fraction immediately), bound bidirectionally to a plain LaTeX source box. Powered by MathLive.
  • Search, filter, and categorize: Search the library, filter by category, and sort by name, newest, or recently changed. Categories can be created, renamed, and deleted (equations move to Uncategorized rather than being deleted).
  • Editor autocomplete: Type $/ anywhere in a note to open a filterable picker of the library; accepting a suggestion replaces the trigger text with the fully delimited equation. Off by default on phones (where it conflicts with the on-screen keyboard); configurable trigger string.
  • Local, out-of-band storage: Settings, the equation catalog, and an action log live in the plugin's own folder — nothing is written to the vault unless you export. The plugin makes no network requests; MathLive's fonts ship inline as data URIs.
  • Export / import catalog: Export the full catalog to any path in the vault, or import one without ever overwriting existing equations (name clashes are suffixed, duplicates are skipped).

Requirements & Installation

  1. Install Plugin: Not yet in the community plugin browser. Copy main.js, manifest.json, and styles.css from a release into <vault>/.obsidian/plugins/equation-library/, then enable it under Settings > Community Plugins.
  2. Configure: In the plugin settings, set the default insert format (inline or block), enable/configure autocomplete, and set the action-log size limit.

How It Fits the Workflow

Research and coursework notes in Obsidian frequently need typeset formulas — problem sets, derivations, model specifications. Equation Library keeps a personal, reusable formula bank alongside the note-taking environment rather than requiring formulas to be re-typed from scratch or copied from external LaTeX references each time.
